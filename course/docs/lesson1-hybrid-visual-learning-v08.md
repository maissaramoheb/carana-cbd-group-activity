## Approved blended learning strategy
- **18 concept-first visualizations**: PESTEL-S, stakeholder power–interest, conflict tree, PIN, SWOT, areas–dimensions, baseline and other sequential tools. One per screen.
- **3 cinematic editorial illustrations**: Scene 1.1 diagnose before prescribing; 3.3 programme duplication/counterpart fatigue; 4.2 triangulate evidence. Only these screens pair cinematic storytelling with the conceptual diagram, sequentially labeled *See the situation* → *Explore the underlying concept*.
- Three micro-decisions in screen 2.1, 4.2 and 4.3; evidence-based feedback; no points, no artificial CARANA findings.
- Enhanced PESTEL-S dimension pictograms, visual exploration progress, and explicit internal/external vs favorable/unfavorable SWOT quadrants.
- Preserve 18 reviewed voice MP3s, 36 checkpoint questions, original practical CARANA activity, current progress keys and approved course design.
