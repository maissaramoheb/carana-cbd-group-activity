# CARANA CBD Lesson 1 · Concept-first Visual Learning Journey v0.7
Source: UNPOL CBD JST Lesson 1 — *Situational Analysis* (2021; PDF file 07/2023).

## Purpose
Illustrations should teach, not decorate. Each screen must reveal a relationship, analytical question, or evidence-led application. Prefer professional conceptual visuals over character scenes. Preserve the approved course layout, narration, interactivity, and existing CARANA exercise.

## Non-negotiable integrity
- Real named frameworks and CBD areas match the curriculum. The extra questions are **independent instructional adaptations**, not quotations from the course or official UN findings.
- Invented practice cases and baseline numbers are labelled illustrative; no CARANA exercise Annex D solution is exposed.
- Narrative illustrations featuring people are *suppressed* on all 18 learning screens in this branch, not deleted from the repository.
- All diagrams use keyboard-accessible buttons, focus styles, live explanation feedback, mobile fallbacks and reduced-motion support.
- Visual exploration is optional and formative; it must not change six existing 6-question checkpoints, local progress, the original activity or any narration.
- The current production course remains unchanged until review and explicit promotion.

## Review criteria
Across 18 screens, verify every conceptual diagram, interaction, script, link and contrast in Safari and mobile. Check voice playback remains 18/18, the 5×6 matrix still has 30 accessible intersections, and quiz gating remains unchanged. Learner pilot required before claiming improved learning effectiveness.
