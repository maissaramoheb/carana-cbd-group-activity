# Visual learning standards

Use the established navy, teal and mint shell, editorial headings and quiet reading surfaces. Keep body text and active control labels legible within that palette. Interface changes should remove observed friction before changing component composition.

Use one principal conceptual visualization per screen when it explains a concept, relationship or decision. Name axes in text, use stable semantic colors with labels, and give semantic buttons a visible focus state, visible-label accessible name and selected state. Use plain feedback to explain the choice. Keep practice formative; examples do not carry grading weight or disclose facilitator responses. A wide matrix may scroll inside a labelled region. Keep the rest of the page within the viewport.

Use around two or three editorial cinematic images per lesson at deliberate moments. Lesson 1 retains 1.1 (diagnose), 3.3 (counterpart fatigue) and 4.2 (triangulation). Pair each image with its interactive concept in sequence: see the situation, explore the underlying concept. Preserve the established art direction. Mark invented context, avoid real-person or UN endorsement implications, provide useful alt text, declare measured intrinsic dimensions and load lazily.

For new lessons first agree objective, learner task, source, expected evidence and participant/facilitator boundary. Test at desktop, tablet and narrow mobile sizes, with keyboard and reduced motion, and retain comparative screenshots. Test video/audio alternatives and include source-based rationale in the review matrix.
