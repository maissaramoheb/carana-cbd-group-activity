# CARANA CBD Lesson 1 comprehensive assessment

The hybrid design has a coherent teaching purpose and fits an experienced professional audience. The most consequential release weakness was reproducibility: a build could silently serve a previous recording alongside an edited transcript or generate paid replacements. A second cluster affected learners directly: confusing persistence and resume behavior, lost quiz choices during review, inaccessible state changes and low contrast.

| Area | Findings and decision |
|---|---|
| Instructional quality | Official objectives and sequencing checked against the local July 2023 PDF; see the instructional matrix. Strong analysis-first framing and course-to-practice transfer. SSR, comparative practice and interpersonal proficiency have narrower evidence than the official classroom objectives. Retain the pilot scope and schedule expert/facilitated validation. |
| Journey | Six distinct short blocks support orientation. Cinematic pairing introduces situation before analysis. The dense final screen already signals transfer; changed copy distinguishes guided practice from independent library access. Back-and-review now preserves same-tab answers. |
| Conceptual visuals | Reviewed diagnostic path, lenses, evidence timeline, PESTEL-S, tree, legal-fit gates, response orbit, PIN iceberg, overlap, capacity tiers, triangulation, stakeholder quadrants, pillars, 30-cell matrix, issue classifier, SWOT, comparison and transfer route. Preserve explanatory choices and feedback. Matrix buttons expose selection at rest and on activation. Small viewports keep table overflow local. |
| Cinematic visuals | Existing three purposeful scenes retained with meaningful alternative text, lazy loading and corrected widths/heights. Examples are illustrative. Imagery and conceptual disclosures resolve different tasks. |
| Narration | Recovered 18 deployed AI MP3s; scripts identical to served trainer JS. Decoded each file end-to-end and exercised playback in browser. Recorded durations 35.496–40.896 seconds. Release lock makes future script/byte mismatch fail. This provenance is not a human read-along, pronunciation or transcript audit for every clip. |
| Assessment | 36 authored questions: practical best-next-step items plus important framework recall. Some distractors are easy to eliminate; no item-response or field performance evidence. All six correct is reasonable as a guided mastery gate with immediate feedback and unlimited retries. Alternatives (score threshold or separate essential items) change how mastery is represented and would need item validation. Keep score, saved format and threshold unchanged; remove avoidable review friction. |
| UI and accessibility | Corrected visible-name mismatches, low-contrast sampled elements, lost focus after re-render and audio error messaging. Original interface remains recognisable. Automated scans and keyboard paths do not establish overall WCAG conformance. |
| Architecture | Static site with explicit data and per-screen renderers; reuse simple templates for future lessons. Some UI strings still assume six sections/three screens, and there is no multi-language content/RTL release. Avoid generalising ahead of Lesson 2 requirements. |
| Performance | Audio now requested when played; images retain lazy loading; fingerprinted URLs support immutable caching. No redesign, framework or new dependencies. See verification for measurements and limits. |
| Privacy and resilience | Course stores browser-local progress and can export it; revalidated loaded values and made write failure visible. Existing web fonts contact a third party with system fallbacks. Build stages public assets explicitly. No analytics or account changes. Learner-side checkpoint key is inspectable and cannot be a high-stakes assessment. |
| Source protection | No official lesson plan published. Course examples and hints are original. The unchanged workbench scenario file has a legacy header mentioning Annex D, but its exported data consists of areas, dimensions, scenario paragraphs and illustrative stakeholders; the workbench contains dormant guide hooks. No matrix model solution was located in reviewed distribution sources. Formal content/rights review still applies to the full distribution. |
