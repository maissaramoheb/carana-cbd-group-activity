# Local AI architecture, security and privacy

Browser → same-origin /api/tutor → authenticated loopback HTTPS gateway → teaching-only retrieval → provider module → existing Ollama at 127.0.0.1:11434. No model tools, shell, filesystem access, remote URLs or browser-selected provider/model are accepted. The static Vercel build contains the UI only; tutor code, knowledge, PDFs, credentials and test evidence are outside the staged web root. The public UI makes no localhost request.

The owner Mac has 24 GiB RAM, 15 logical CPUs, Apple arm64 Mac17,9, about 67 GiB disk free at discovery. Existing Ollama 0.40.16 was preserved. Existing gemma4:26b (~17 GB) was not loaded given available memory headroom; glm-ocr is not a suitable tutoring model. Assessed lightweight downloads: qwen3:0.6b (~523 MB), qwen3:1.7b (~1.4 GB), and assessed qwen3:4b (~2.5 GB, completed and tested); no existing models/settings were removed. Gateway controls: bind127.0.0.1 only; TLS1.2 minimum; exact localhost/127.0.0.1 Host and Origin; no permissive CORS; random192-bit bearer access code, timing-safe comparison; ephemeral private directory0700, certificate key/access file0600. Gateway credentials are generated at launch, never bundled, hardcoded or logged. Browser access is manually entered, held in memory and sent only to the same-origin API. This pilot token protects against other origins/accidental access; it is not an institutional identity/account system. Other processes under the same local user remain within the trusted-host boundary.

Limits: 8 KiB requests, 1200-character questions, strict allowlisted fields and valid lesson/screen/mode; 12 authorized questions/minute shared pilot, 40 attempts/minute/address, 60 status requests/minute/address; one inference; 45-second deadline; cancellation closes model work; fixed context4096 / fast output420 tokens; optional bounded-reasoning benchmark1800tokens; response length and source-ID validation; unsupported numeric claims rejected; no private question logging. API failures give503 without fabricated content. Protected keys and active checkpoints return explicitly labelled deterministic concept guidance and never call inference.

NDJSON content is delivered after the complete generated JSON/source checks, not token-by-token model streaming. Loading, showing guidance, cancel and error states reflect this. Model text is inserted with textContent. Structured output does not prove factual grounding: [Ollama structured-output reference](https://docs.ollama.com/capabilities/structured-outputs), inspected during this run. See MODEL_EVALUATION.md for retained hallucination evidence and remaining semantic risk.

## Local launch

Run npm run build, then npm run tutor:local. Open the printed HTTPS localhost URL. Runtime metadata prints the private access-file path, never its value. Open that file locally to enter the current access code in the panel. Certificate is self-signed, valid seven days, scoped to localhost/127.0.0.1 and not installed in system trust. A local browser trust warning is expected; evaluate certificate locally. Automated review trusts/ignores that specific local review certificate only. No global TLS bypass or public certificate claim.

## Secure public AI remains a separate approval

No tunnel, inbound firewall changes, public Mac listener or Vercel model proxy was configured. For remote institutional pilot: approve an authenticated private connection/connector, trusted HTTPS, server-side credential storage and rotation, identity/rate/abuse policy, network allowlisting, service supervision, availability/cost/resource policy and independent security review. Prefer an outbound private connector to a controlled server intermediary; never expose raw11434 or an unlimited gateway. A paid hosting/tunnel choice and public service activation need separate authorization. Static course, Read Screen, practicals and Notebook work without the Mac. Public AI stays explicitly unavailable until those decisions and verification are complete.

Conversation is ephemeral, bounded to12 UI messages, cleared when context changes; each request contains only current question plus lessonId/screenId/mode, no automatic history/drafts. Users are warned against confidential/personal/operational material. This prototype is not a professional assessment system or a claim of comprehensive prompt-injection immunity.

Teaching qualification is HOLD independently of connectivity. Resolve the retained model-quality failures and obtain expert acceptance before enabling a learner pilot or public AI. Raw fast mode is the reproducible engineering prototype, not a selected teaching model.
