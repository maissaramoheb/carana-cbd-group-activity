# CARANA Run 08 — EN / FR / AR Terminology Glossary

> **Governance Notice:** Independent CARANA trilingual instructional glossary prepared for Run 08. Uses established UNTERM and UNPOL RBM conventions where verifiable and explicitly marks proposed terms pending human linguistic and UNPOL SME review. Not an official UN publication or UN-approved translation.

## Verification Status Legend

- `unterm-established`: Established in public UNTERM / UN RBB / DPO terminology conventions; subject to mission context verification.
- `unpol-source`: Derived from public UNPOL / SGF / CBD instructional terminology conventions; requires SME sign-off in FR/AR.
- `carana-adapted`: CARANA pedagogical / scenario term retained or adapted consistently across lessons and workbenches.
- `proposed-pending-review`: Proposed didactic equivalent pending bilingual UNPOL / UN translation review.
